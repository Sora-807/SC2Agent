## 空值约定

| 情况 | 填法 |
|---|---|
| 矿区无建筑 | 建筑/部队表填 `无` |
| 矿区无部队 | 部队表填 `无` |
| 建筑无挂件 | 挂件列填 `无`（生产建筑）或 `—`（非生产建筑） |
| 建筑空闲 | 正在做什么填 `空闲` |
| 供给站状态 | `已降下` / `已升起` |
| 精炼厂状态 | `采气`（有SCV在采）/ `空闲`（无SCV） |
| 地堡状态 | `驻扎 terran/marine ×N` / `空闲` |
| 在建建筑 | 正在做什么填 `建造中（XX%）` |
| 在建挂件 | 挂件列填 `在建` |
| 兵种正在训练和队列都为0 | 不列该行 |
| 敌方单位 | 行前缀 `敌方：`，同兵种也按集群分 |
| 无视野的区域 | 矿区段填 `无视野` |

## 列头说明

| 表 | 列头 | 含义 |
|---|---|---|
| 资源 | 矿物储量 / 气体储量 / 补给（已用/上限） | 当前矿物/气体/人口（已用/上限） |
| 工人分布 | 采矿工 / 采气工 / 建造工 / 侦查工 / 空闲工 | SCV 按任务分布，顺序：干活在前空闲在末尾 |
| 建筑汇总 | 建筑类型 / 总数 / 科技挂件 / 双倍挂件 / 无挂件 / 在建 | 全局建筑统计；挂件列只对生产建筑有意义，非生产建筑填 — |
| 部队汇总 | 兵种 / 数目 | 全局我方单位统计，含 SCV |
| 生产序列 | 兵种 / 正在训练 / 待训练队列 | 每种兵在训几个、队列里排几个；都为0不列 |
| 区域·建筑 | 建筑 / 坐标 / 挂件 / 正在做什么 | 该矿区内所有建筑，含防御建筑 |
| 区域·部队 | 兵种 / 集群 / 数量 / 坐标 / 血量% / 绝对血量 | 我方+视野内敌方；按集群分组 |

## 机器可读 facts 的口径（算术前先看）

| 键 | 口径 | 用途 |
|---|---|---|
| `buildings` | **只数已完工**（build_progress≥1） | 判能不能用 / 前置是否就绪 / 产线是否在线 |
| 「建筑汇总」表·总数列 | **含在建** | 数量算术一律用这列：总共几座、够不够人口/产线 |

坑：在建期间 buildings 比总数少 —— 拿 buildings 当总数会误判「少建了」而重提。
敌方信息在「风险/alerts」段的 enemy_contact（只在敌人进视野时报；没报=视野内没有，
不是系统不给）。

## 格点网格模式（有 bbox 时）

有 bbox 时 observe 返回格点网格（已有格式，保持不变）：

```
# 区域 live（x30–55，y25–45，step=1）

| y\x | 30 | 31 | 32 | ... |
|---|:---:|:---:|:---:|---|
| **45** | · | · | · | ... |
| **43** | · | · | ✗ | ... |
```

词表：`·` 空可建 · `✗` 地形障碍 · `gas/CC/M` 预设固定点 · 其余标签 = 槽位正式名

step 自动计算：格点 ≤14×14 全量返回（step=1），超出自动降密度，结果标注 `step=N`。
