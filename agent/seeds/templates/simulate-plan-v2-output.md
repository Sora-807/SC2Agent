## 空值约定

| 场景 | 空值表示 |
|---|---|
| 无 error | 健康检查表不输出 error 行，表格下方注明 `🔴 error：无` |
| 无 warn | 健康检查表不输出 warn 行，表格下方注明 `🟡 warn：无` |
| 无 info（无策略装配时） | 表格下方注明 `⚪ info：无策略装配，跳过` |
| 无 skipped 项 | 队列执行状态表照常列出所有项，无 skipped 行即无 |
| 无已完成升级 | 注明 `已完成升级：无` |
| 产线明细无建筑 | 产线明细表为空表（只有表头），下方注明 `无生产建筑` |
