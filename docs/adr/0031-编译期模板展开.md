# ADR-0031：策略模板的编译期展开（imports + `_lib.yaml`）

日期：2026-08-23 ｜ 状态：已采纳（批 A，执行记录见 WORKLOG §0.41） ｜ 影响：flow/manifest、view/strategies、契约 rev 15

## 背景

策略文件放开可写（二十七轮）之后，"每个策略都从零手写全部 step" 成了主要成本：
集结、推进、堵口、驻守、蛙跳这些打法在策略间重复出现，改一处漏三处。
自然的冲动是恢复 ADR-0004 时代的"可组合战术模块"—— 但那条路被 ADR-0028
刻意废弃过（运行时可组合模块带来实例状态、热切、多实例的复杂度，换来的
灵活性 V1 吃不消）。同时用户拍板保留"游戏过程中能换策略"（热切走整份文件
切换，见批 C），所以模块化不能引入新的运行时形态。

## 决定

**模板 = 编译期文本展开，不是运行时模块。**

1. **模板库文件**：出厂种子随版本库走（`modules/flow/data/_lib.yaml`；`runtime/`
   整目录 gitignore），StrategyStore 建目录时播种成 `runtime/strategies/_lib.yaml`
   工作副本（人改副本，与 default 策略"内置常量播种"同一模式）。库体是
   `step_templates:` 一层，
   每个模板是裸 step（branches/locals/可读名）+ `params` 声明 + `exits`
   接口契约（模板可能产生的 exit_step (kind, reason) 集合，声明与 branches
   逐对一致，谎报契约在 `parse_lib` 就红）。
2. **策略侧 `imports:` 节**（parse 阶段展开，`flow/templates.py`）：
   `键名 = step_id`；`params` 绑定模板参数；**两层词法作用域** —— 模板体只
   看得见自己的 params（引用未声明名 = 编译错误，不静默捕获策略级名字），
   绑定值可以引用策略级 `{param: Y}`（桥接节点原样保留，运行时求值）。
3. **接线契约**：edges 引用导入 step 的 (kind, reason) 必须落在模板 exits 里
   —— 接错线当场红，不用等死边检查的间接报错。
4. **运行时零改动**：展开产物与手写策略同构；图可达/死边/谓词签名/环出口等
   全部既有校验在展开后照跑。`static/strategy` 增 `imported: [step_id…]`
   标记（rev 15）供前端显示「模板」出身，仅此而已。
5. **锁定语义**：`_` 前缀 = 锁定（复用策略锁定前缀机制）。`_lib.yaml` 只有
   人能改；agent 经 `read strategies/_lib.yaml`（REST `GET /api/strategies/_lib`
   只读端点）看原文，写被指路拒绝。

## 与 ADR-0028 的关系（为什么这不是反转）

ADR-0028 废的是**运行时可组合模块**：模块有实例状态、参与热切、允许多实例，
引擎要理解"模块边界"。本 ADR 的模板在 parse 阶段就消失了 —— 引擎、协议、
装配看到的仍然是一份单体策略。热切 V1（批 C）切换的也是**展开后的整份策略**，
模板不参与运行时任何决策。换言之：ADR-0028 的"运行时无模块"不变量原样成立，
本 ADR 只是把 authoring 面的重复收敛到编译期。

如果未来有人要求"模板带自己的状态/参数运行时可变"，那是重新打开
ADR-0028 的讨论，不是本机制的延伸。

## 反例（明确不做）

- **模板套模板**：lib 只含裸 step（键白名单锁死）。嵌套展开的组合爆炸与
  调试困难，收益撑不起。
- **模板内 exit_strategy**：终局是策略作者的权 —— 模板只提供 exit_step
  接口，往哪走由策略的 edges 决定。
- **模板体引用策略级参数/definitions**：暗渠比错误贵。要桥接就在 imports
  的 params 里显式绑 `{param: 名字}`。
- **JSON 中间层**：读写、校验全程 YAML（用户拍板），校验器即编译器。

## 种子模板（首版六件，全部经编译 + 引擎转移验证）

`gather`（集结）、`push`（推进，每帧续压语义已注记）、`hold_ramp`（堵口：
not+arrived/move_to/hold_position）、`garrison`（驻守入口）、
`armor_hop`/`inf_hop`（步坦蛙跳，提炼自 tank_marine_push；definitions 属
策略级，模板内以 point_toward 内联等价实现）。
