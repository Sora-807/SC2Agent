# ADR-0023 浏览器信息架构、时间线回放与可视化 Flow 编辑

- 状态：已确认草案
- 替代：无（细化 0022）
- 范围：第一层级页面、实时游戏选项卡、复盘、规划工具、时间线、流程图编辑器

## 背景

用户补充了完整界面构想。本文档固化界面信息架构，并标注哪些 V1 可实现、哪些作为 V1.5/后续。

## 决定

### 1. 第一层级

```text
实时游戏
复盘
规划
```

每个第一层级内部有自己的选项卡。

### 2. 实时游戏

选项卡：

```text
概览
地图
生产队列
Flow 状态图
```

#### 2.1 概览

- 上方：生产队列长条 + 晶体矿/瓦斯曲线。
- 左下：地图。
- 右下：Flow 状态图。
- 所有面板可折叠、可拖动布局。
- 布局持久化到本地；点击面板可跳转到对应完整选项卡。

#### 2.2 地图选项卡

- 底层地图数据与地图规划使用同一份地形数据。
- 地图刷新节拍按 ADR-0025：V1 默认 1 秒；关键事件可即时刷新。
- 叠加层：
  - 已建成建筑、在建建筑及进度；
  - 待建造建筑：未来 30 秒内将建造的虚拟位置和时间。build 操作必须携带 placement（精确坐标、区域、预留区或 placement policy），没有 placement 的 build 在编译期即为非法；因此未来建筑始终有位置可显示，其中按区域/策略推导的位置标记为“预计位置”。
  - 单位集群；若单位已被 flow 分组，以 flow 组为单位展示；
  - 组图标展示当前执行战术；
  - agent 当前 Intent / 进攻路线：当前坐标为点，虚线指向目标点，V1 无视障碍物；2.5D 抛物线路径列入后续升级；
  - 生产建筑浮动显示正在训练的单位；
  - 区域边界与观察区。
  - GameState.map_layers 图层：菌毯覆盖、能量场范围、挂件预留位、视野等，均可在图层开关中单独显示/隐藏。

#### 2.3 生产队列选项卡

- 预估接下来一段时间的建造/训练队列泳道图。
- 下方或同屏显示晶体矿/瓦斯曲线。
- 数据来源：planner 对当前 production_sequence 的滚动投影。
- 与概览顶部面板共用同一份数据。

#### 2.4 Flow 状态图

- 展示 Flow 的有环策略图。
- 按 production / combat / defense 等类别分组为子图。
- 节点为圆形，显示预定进度，例如 `SCV 2/4`。
- 正在执行节点显示旋转进度条。
- 边悬停显示切换原因：正常完成、遭遇敌袭、兵力不足、用户取消等。
- 节点点击可展开内部 step DAG 与当前 if 分支。

### 3. 顶部时间线

- 实时游戏和复盘都有时间线。
- 保存的数据：
  - 定期完整 GameState 快照；
  - FlowRuntimeState；
  - 关键事件与转移日志；
  - if 分支判断日志（可配置）。
- V1 时间线采用“快照 + 日志回放”：
  - 默认每 5 秒一份完整快照，关键转移立即快照；
  - 拖动到时间点时，恢复最近快照并重放日志；
  - 时间线上可见快照点、警报、策略转移标记。
- 限制：
  - V1 不做任意帧连续平滑回放；只能跳转到快照/事件点。
  - 实时游戏中拖回历史时进入只读回看模式，live 继续在后台运行，提供“回到实时”按钮。
  - 快照间隔与保留容量可配置，防止 workspace 无限膨胀。

### 4. 复盘

- 顶部入口选择过去对局。
- 内部与实时游戏相同布局、相同选项卡、相同时间线逻辑。
- 多一个返回按钮。
- 数据只读。

### 5. 规划

#### 5.1 地图规划

- 左侧文件栏。
- 地图选择下拉框，带搜索。
- 红方/蓝方切换按钮。
- 默认地图模板：
  - 地形数据、默认矿区区域、开局基地位置；
  - 模板只读；要编辑必须“复制并新建草稿”。
- 右侧地图画布：
  - 图层开关：矿区范围、建筑、单位标记、区域、预留区；
  - 右侧工具：建筑/标记/区域工具。
- 人与 agent 都可操作和理解：所有画布操作都转化为结构化 `map_plan` patch。

#### 5.2 生产规划

- 左侧文件栏。
- 顶部：矿物/瓦斯曲线。
- 中部：泳道图。
- 底部：单位/建筑/科技展示，点击加入队列。
- 支持自定义开始状态。
- 支持从复盘页面把某一帧 GameState 发送到生产规划作为草稿起点。

#### 5.3 Flow 规划

- 左侧分“模块库”和“策略库”两栏。
- 点击模块/策略，右侧显示图。
- 右侧支持可视化装配：节点、参数、trigger、退出原因边。
- 支持导入一段连续时间的 state，查看 Flow 在该段状态上的运行过程。
- 调试日志两级：
  - 重要日志：step 之间跳跃、原因、时间、状态变化；
  - 精细日志：每个 step 内每帧 if 的判断路径和结果。
- 精细日志量大，V1 只保存最近窗口或抽样，并允许开启/关闭。

### 6. 可视化方块图编辑器

- 原子操作固定，因此每个节点可配置参数，像程序框图一样编辑。
- 节点类型：Selector、Action、Predicate、Step、Strategy、Trigger、Exit。
- 节点连线受 schema 约束，非法连线直接禁止。
- 编辑结果编译为模块 manifest 或 FlowSpec。
- 该编辑器只存在于离线规划；live 中只读或不可编辑。

### 7. 种族切换

- 规划工作台顶部有种族切换按钮。
- 地图规划的默认模板、单位面板、Flow 模块库随种族过滤。
- 实时游戏按实际对局种族显示；复盘为只读种族信息。

## 功能分级

| 功能 | V1 | V1.5/后续 |
|---|---|---|
| 第一层级 + 选项卡 | 是 | — |
| 概览可折叠/拖动布局 | 是 | — |
| 地图动态叠加 | 是 | 精细化战斗路径 |
| 未来 30 秒虚拟建筑 | 是（有确定位置的） | 全自动摆位预测 |
| 生产队列泳道 + 曲线 | 是 | — |
| Flow 有环图与原因边 | 是 | 更强子图布局 |
| 时间线跳转快照/事件 | 是 | 任意帧平滑回放 |
| 复盘同布局 | 是 | — |
| 地图规划/生产规划基础 | 是 | — |
| 从复盘导入一帧到生产规划 | 是 | — |
| Flow 规划可视化编辑 | 基础版 | 完整方块图编辑器 |
| 导入连续 state 到 Flow 规划 | V1 简化 | 完整回放 |
| 每帧 if 精细日志 | 抽样/窗口 | 全量可选 |

## 反例（明确禁止）

- 前端自己实现第二份 simulate 或约束。
- 时间线只保存 UI 数据，不能恢复后端状态。
- 实时拖回历史时停止 live 数据采集。
- 默认地图模板被用户直接修改。
- live 中打开方块图编辑器修改模块逻辑。
- 地图/生产规划默认叠加在 live 地图上。

## 验收标准

1. 三个第一层级页面可切换，内部选项卡符合定义。
2. 概览面板可折叠、拖动并保存布局。
3. 地图叠加层至少包含建筑、进度、单位集群、flow 组、当前战术、未来 30 秒确定建筑。
4. 生产队列与资源曲线来自 planner，滚动更新。
5. Flow 状态图显示分组、节点进度、当前节点动画、边原因。
6. 时间线可跳转到快照/事件点并恢复对应后端状态；快照点清晰可见。
7. 复盘页可进入历史对局并按相同方式操作。
8. 规划页支持红蓝方与种族切换；默认模板只读，草稿复制编辑。
9. Flow 规划可查看重要日志和精细日志窗口。
